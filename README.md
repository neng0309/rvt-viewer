# 3D Model Viewer (ดูอย่างเดียว)

ไฟล์ที่ต้องใช้: `index.html` ไฟล์เดียว + โฟลเดอร์ `models/` ที่ใส่โมเดล
รองรับ: **.ifc** (คลิกดูข้อมูลชิ้นส่วนได้ครบ), .fbx, .obj (+ .mtl), .glb, .gltf

## ควบคุม
- ลาก = เลื่อน · **Ctrl (หรือ Shift) + ลาก = หมุน** · ล้อเมาส์ = ซูมสมูท (ซูมเข้าหาตำแหน่งเมาส์)
- คลิกชิ้นส่วน = ไฮไลต์ + แสดงข้อมูล (ปิดด้วย × หรือ Esc)
- Section Box: กดปุ่มกล่องเส้นประ แล้วลากจุดสีน้ำเงินที่หน้ากล่องเพื่อรูดตัดโมเดลเข้า/ออก
- มือถือ: 1 นิ้ว = หมุน · 2 นิ้ว = เลื่อน/ซูม

## ขึ้น GitHub
1. อัพโหลด `index.html` ที่หน้าแรกของ repo
2. สร้างโฟลเดอร์ `models` แล้วอัพไฟล์โมเดลเข้าไป
3. Settings → Pages → Deploy from a branch → `main` / root
4. ลิงก์: `https://<username>.github.io/<repo>/?model=models/ชื่อไฟล์.ifc` (เติม `&ui=0` เพื่อซ่อนปุ่ม)

## Export จาก Revit
- **IFC** แนะนำที่สุด: File → Export → IFC (ได้ข้อมูลชิ้นส่วน/ชั้น/Property ครบ)
- FBX / OBJ ใช้ได้ แต่คลิกแล้วเห็นแค่ชื่อออบเจกต์
- ไฟล์ละไม่เกิน 100 MB (อัพผ่านหน้าเว็บไม่เกิน 25 MB)
